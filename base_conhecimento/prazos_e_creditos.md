# Prazos de contestação e crédito

> Documento fictício, criado apenas para demonstração.

## Prazo para contestar uma compra
O cliente pode contestar uma compra em até 90 dias corridos a partir da data da compra. Após esse prazo, a contestação é analisada como exceção.

## Quando o valor volta para o cliente
O estorno provisório volta como crédito na próxima fatura fechada após a abertura da contestação.

## Análise definitiva
A análise definitiva da contestação é concluída em até 45 dias. Se a compra for confirmada como legítima, o crédito provisório é revertido e o cliente é avisado com antecedência. Por isso o estorno nunca deve ser apresentado como definitivo.
