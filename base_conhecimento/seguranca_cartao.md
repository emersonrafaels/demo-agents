# Segurança do cartão

> Documento fictício, criado apenas para demonstração.

## Novo cartão após bloqueio
Depois do bloqueio preventivo, um novo cartão físico é enviado em até 5 dias úteis. O cartão virtual pode ser gerado no app imediatamente para compras online.

## Golpes comuns
O banco nunca pede senha, código de verificação ou transferência para uma "conta segura". Oriente o cliente a desligar e ligar para a central oficial em caso de dúvida.
